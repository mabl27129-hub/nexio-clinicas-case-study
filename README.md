# Caso de estudio: NEXIO Clínicas

Portafolio de Miguel Alonzo Barrios (Curitiba, Brasil). Asistente de WhatsApp con IA, agenda y CRM multi-clínica.

La página es un solo archivo, `index.html`, sin dependencias ni build.

Todo lo que dice la página sale de inspeccionar el proyecto real. Lo que no está demostrado (métricas de uso, clientes, calidad conversacional medida, pruebas de carga, cobro automático) está marcado como pendiente en la sección "Estado actual del producto". Las capturas marcadas como "vista conceptual" son maquetas, no capturas del producto.
